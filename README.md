# OrangeHRM Playwright POM Practice Project

Playwright + JavaScript Page Object Model framework with:
- pages/
- locators/
- fixtures/
- testdata/
- utils/
- tests/

## Setup
npm install
npx playwright install

## Run all tests
npx playwright test

## Run headed
npx playwright test --headed

## Debug
npx playwright test --debug

## Open report
npx playwright show-report
